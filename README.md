# SCIENCEGAMES · RICE

เว็บเกมเปิดภาพ 25 ช่องเรื่องการปฐมพยาบาล RICE พร้อมคำถามถูก–ผิด เฉลย และคะแนน

## เล่นทันทีในเครื่อง

ดับเบิลคลิก **index.html** ในโฟลเดอร์นี้ เปิดด้วย Chrome หรือ Microsoft Edge แล้วเล่นได้เลย ไม่ต้องติดตั้ง Node.js ไม่ต้องเปิดเซิร์ฟเวอร์ และไม่ต้องต่ออินเทอร์เน็ตสำหรับการเล่น

ต้องเก็บ `index.html`, `styles.css`, `game.js`, `questions.js`, `app.js` และโฟลเดอร์ `assets` ไว้ด้วยกันตามโครงสร้างนี้

## กติกา

- ใส่ชื่อ เลือกตัวละคร และปรับเวลาตอบแต่ละข้อ 5–60 วินาที ครั้งละ 5 วินาที
- เวลารวมทั้งเกมนับถอยหลัง 15 นาที หมดเวลาแล้วจบเกมทันที รวมถึงขณะตอบคำถามหรืออ่านเฉลย
- กระดาน 25 ช่อง แต่ละแถวมีคะแนน 500 / 400 / 300 / 200 / 100 รวมสูงสุด 7,500 คะแนน
- ตอบถูกได้คะแนนของช่อง ตอบผิดหรือหมดเวลาได้ 0 คะแนน ทุกกรณีเปิดภาพของช่องนั้นและไม่สามารถตอบซ้ำ
- ช่องที่เปิดแล้วไม่มีตัวเลข และรวมเป็นภาพต่อเนื่องเมื่อเปิดครบ
- เกมล่าสุดและประวัติ 20 เกมบันทึกในเบราว์เซอร์ของเครื่องเดิม รีเฟรชแล้วเล่นต่อได้ เวลารวมและเวลาคำถามไม่เริ่มใหม่
- การล้างข้อมูลเบราว์เซอร์ เปลี่ยนเบราว์เซอร์ ย้ายไฟล์ หรือเปลี่ยนจากไฟล์ในเครื่องเป็นเว็บออนไลน์ อาจทำให้ไม่พบข้อมูลที่บันทึกไว้เดิม

## อัปขึ้น GitHub Pages

1. สร้าง repository ใน GitHub
2. อัปโหลดไฟล์และโฟลเดอร์ **ที่อยู่ข้างใน ScienceGames** ลงรากของ repository ให้เห็น `index.html` อยู่ระดับแรก
3. ไปที่ **Settings → Pages → Build and deployment**
4. เลือก **Deploy from a branch** แล้วเลือก **main** และ **/ (root)** จากนั้นกด **Save**
5. รอ GitHub แสดงลิงก์เว็บไซต์ของ repository

เว็บใช้พาธสัมพัทธ์ จึงใช้ได้ทั้ง GitHub Pages แบบโปรเจกต์และเปิดไฟล์ในเครื่อง ไม่มีรหัสผ่าน โทเคน หรือข้อมูลบัญชี Sites รวมอยู่ในโฟลเดอร์นี้

## แก้คำถามและเฉลย

เปิด **questions.js** แก้รายการใน `QUESTIONS` มี 25 ข้อเรียงจากซ้ายไปขวา บนลงล่าง

แต่ละข้อเขียนเป็น `q('คำถาม', true, 'คำอธิบายเฉลย')` หรือใช้ `false` หากข้อความนั้นผิด ใช้ `\n` เพื่อแบ่งบรรทัดคำถาม สามารถระบุ URL อ้างอิงเป็นอาร์กิวเมนต์ที่ 4 ได้

ชุดคำถามเริ่มต้นอ้างอิง [NHS](https://www.nhs.uk/conditions/sprains-and-strains/) และ [St John Ambulance](https://www.sja.org.uk/first-aid-advice/sprains-and-strains/) และสามารถเปลี่ยนเป็นชุดคำถามของครูได้

## โครงสร้างไฟล์

```text
ScienceGames/
  index.html          หน้าเว็บ เปิดเล่นได้โดยตรง
  styles.css          ตำแหน่งองค์ประกอบและรูปแบบ
  app.js              ระบบหน้าเกมและการบันทึก
  game.js             กติกา เวลา และคะแนน
  questions.js        คำถามพร้อมคำตอบและเฉลย
  assets/             ภาพ ฟอนต์ และใบอนุญาตฟอนต์
  tests/              ทดสอบกติกาเกม
  package.json        คำสั่งเสริมสำหรับผู้พัฒนา
  server.mjs          เซิร์ฟเวอร์เสริม (ไม่จำเป็นต่อการเล่น)
```

สำหรับผู้พัฒนาที่มี Node.js: `npm test` เพื่อตรวจระบบ หรือ `npm start` เพื่อเปิดผ่าน http://127.0.0.1:4173 แทนการเปิดไฟล์โดยตรง

ฟอนต์ Nunito และ Noto Sans Thai ฝังไว้ใน `styles.css` เพื่อให้เปิดไฟล์ออฟไลน์ได้โดยไม่ต้องโหลดฟอนต์ข้าม origin และเก็บไฟล์ต้นฉบับพร้อมใบอนุญาต OFL ใน `assets/`

การตรวจสอบล่าสุด: ผ่าน 16 รายการ ครอบคลุมกติกา คะแนน เวลา 15 นาที การกู้เกม ลำดับสคริปต์สำหรับ file:// และความครบของไฟล์ภาพ/ฟอนต์ เครื่องมือตรวจเบราว์เซอร์ของผู้ช่วยไม่อนุญาตให้เปิด URL แบบ file:// จึงไม่ได้ยืนยันการดับเบิลคลิกด้วยเบราว์เซอร์จริง

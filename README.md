# RICE RALLY · RICE

เกมเปิดภาพ 25 ช่องสำหรับห้ากลุ่ม ผู้ดำเนินเกมเปิดเฉลยแล้วเลือกกลุ่มที่ได้รับคะแนน

## เปิดเล่น

ดับเบิลคลิก **index.html** ใน Chrome หรือ Microsoft Edge เก็บไฟล์ HTML, CSS, JavaScript และโฟลเดอร์ `assets` ไว้ด้วยกัน เกมใช้รูปและฟอนต์ในเครื่องและเล่นแบบออฟไลน์ได้

1. กรอกชื่อกลุ่ม A–E ช่องที่เว้นว่างจะใช้ชื่อกลุ่มตามตัวอักษร กด **เริ่มเกม** เพื่อเริ่มเวลารวม 15 นาที
2. เลือกช่องบนกระดาน ให้กลุ่มตอบด้วยวาจา แล้วกด **ดูเฉลย**
3. กดชื่อกลุ่มที่ได้รับคะแนน หรือเลือก **ไม่มีทีมได้คะแนน** ทุกครั้งที่ตัดสินแล้วจะเปิดชิ้นภาพของช่องนั้นและกลับสู่กระดาน คะแนนของแต่ละกลุ่มแสดงเหนือกระดาน
4. เมื่อเปิดครบ 25 ช่องหรือครบ 15 นาที เกมจะแสดงคะแนนทั้งห้ากลุ่มเรียงจากมากไปน้อย เมื่อหมดเวลาขณะเปิดคำถามหรือเลือกกลุ่ม ช่องนั้นจะได้ 0 คะแนน

เกมบันทึกในเบราว์เซอร์ของเครื่องที่เล่น กด **เล่นต่อ** เพื่อกลับมายังคำถามหรือเฉลยเดิม เวลารวมเดินต่อแม้ปิดหน้าเว็บ ประวัติรอบกลุ่มเก็บไว้ล่าสุด 20 รอบ รอบผู้เล่นเดี่ยวจากเว็บเวอร์ชันเดิมเก็บคนละรายการกับรอบกลุ่ม การย้ายไฟล์ เปลี่ยนเบราว์เซอร์ หรือล้างข้อมูลเบราว์เซอร์มีผลต่อการเข้าถึงเกมที่บันทึกไว้

## แก้คำถามและเฉลย

เปิด **questions.js** ข้อเรียงจากซ้ายไปขวา แถวละห้าข้อ เริ่มจาก 500 คะแนนลงมาถึง 100 คะแนน

- คำถามปลายเปิดแก้ที่ `text` และ `answer`
- คำถามตัวเลือกใช้ `choice(คำถาม, รายการตัวเลือก, ลำดับเฉลย)` โดยลำดับ 0–3 ตรงกับตัวเลือกที่ 1–4 ตัวเลือกมีไว้ให้อ่าน ผู้ดำเนินเกมเป็นผู้ให้คะแนน
- ข้อภาพใช้ `photo(เลขภาพ, คำถาม, คำบรรยายภาพ, เฉลย)` ภาพจริงอยู่ใน `assets/question-100-1.jpg` ถึง `assets/question-100-4.jpg`

## อัปขึ้น GitHub Pages

วางไฟล์ทั้งหมดในโฟลเดอร์นี้ที่รากของ repository ให้เห็น `index.html` ที่ระดับแรก ใน **Settings → Pages** เลือก **Deploy from a branch → main → / (root)** แล้วกด **Save**

สำหรับผู้พัฒนาที่มี Node.js ใช้ `npm test` เพื่อตรวจระบบ หรือ `npm start` เพื่อเปิดเซิร์ฟเวอร์สำหรับทดสอบที่ `http://127.0.0.1:4173` ฟอนต์ Nunito และ Noto Sans Thai ฝังใน CSS พร้อมใบอนุญาตต้นฉบับในโฟลเดอร์ assets
